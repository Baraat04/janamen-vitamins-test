# Витамины Jana Men — 3D (демо)

Отдельная тестовая версия новой витрины витаминов. На ней 3D‑банки, ролик и карточки продуктов, шапка и футер сайта Jana Jol.
Это одна страница. Ссылки на другие разделы («Рейтинг», «Новости», «Войти»…) ведут на https://janajol.online.

## Запустить у себя

```
npm install
npm run dev        # http://localhost:3130
```

## Залить на GitHub и Vercel

1. Создать пустой репозиторий на GitHub и залить в него эту папку:
   ```
   git init
   git add .
   git commit -m "Витрина витаминов 3D — демо"
   git branch -M main
   git remote add origin https://github.com/<аккаунт>/<репозиторий>.git
   git push -u origin main
   ```
2. На vercel.com нажать «Add New → Project», выбрать этот репозиторий и нажать Deploy.
   Vercel сам поймёт, что это Next.js. Переменные окружения не нужны.
3. Ссылку вида `https://<проект>.vercel.app` можно открыть на телефоне и отправить другим.

Поисковики страницу не индексируют (`robots: noindex`): это тест.

## Обновить демо из основного проекта

Если витрину поправили в основном проекте (`frontend/app/vitamins-3d`), скопировать изменения сюда:

```
npm run sync
```

Команда берёт файлы из `../frontend/frontend`. Если основной проект лежит в другом месте, укажите путь:
`node sync.mjs "путь/к/frontend/frontend"`.
